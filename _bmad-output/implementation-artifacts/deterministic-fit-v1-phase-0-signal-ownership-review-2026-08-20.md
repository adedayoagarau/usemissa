# deterministic-fit-v1 Phase 0 signal ownership review

This Phase 0 ownership, privacy, retention, provenance, and undo review is approved with open production/promotion dependencies. The current execution state is pre-production and replay-only. It does not create a migration, change a serving path, or authorize personalized ordering.

## Evidence boundary

The current repository has two runtime paths. Compatibility storage remains available when `DATABASE_URL` is absent or `MISSA_OPPORTUNITY_REPOSITORY` is not `postgres` ([`apps/web/lib/opportunityRepository.ts:L264-L271`](../../apps/web/lib/opportunityRepository.ts#L264-L271)). Production ownership is now partially verified for schema/catalogue facts, while Auth, durable signal provenance, and canonical safety/dispute ownership remain open.

## Retention and deletion acceptance rules

For any later production or promotion review, the owner must confirm for every creator signal:

1. The canonical owner and read path are named.
2. The origin (`creator-explicit`, `creator-action`, `creator-inferred`, or system context) is stored or recoverable.
3. Observation time, effective time, schema/taxonomy/source version, and confidence are available.
4. Edit, clear, pause, delete, reset, export, and account-deletion behavior are explicit.
5. Derived recommendation context can be invalidated without deleting canonical Tracker or Opportunity history incorrectly.
6. Public DTOs cannot expose private preferences, Work, eligibility values, saved searches, follows, account IDs, or matching details.
7. Analytics cannot mutate canonical state and duplicate events are controlled by idempotency identity.

- Approve durable recommendation-signal provenance and customer undo/clear semantics.
- Confirm production Neon Auth and Tracker behavior for accounts without completed Profiles.
- Confirm retention/deletion owners for accessibility and other private matching inputs.

## Review outcome

The Phase 0 matrix is approved for Phase 1 pure policy/replay work. The unresolved rows remain explicit dependencies for later adapters, shadow evaluation, and serving promotion. No live shadow invocation, onboarding question, or personalized order is authorized by this approval.

## Production verification addendum

The production database contains the canonical Opportunity, version, source, taxonomy, Profile, Tracker, analytics, publication-review, and migration tables. The read-only snapshot contained 3,249 Opportunities and 668 published/open records. It also showed zero Neon Auth users, zero saved searches, zero organization follows, and no recommendation event vocabulary. These facts confirm that production catalogue evidence is available for replay, but do not establish a representative creator-signal corpus.

Publication review has a persisted safety check for unsafe submission destinations, but no version-bound general safety/dispute/removal authority. The ownership decision is therefore unchanged: publication-review safety is provisional evidence; it cannot be promoted to canonical recommendation safety authority without a versioned lifecycle and correction/undo semantics.
