# Missa

Missa is a source-first opportunity library and submission workspace for
creators and organizations. It helps people find grants, magazines,
residencies, fellowships, contests, awards, and other submission opportunities,
then compare the source details before deciding where to spend their time.

## Public discovery

- [Missa](https://www.usemissa.com/)
- [Browse opportunities](https://www.usemissa.com/opportunities-preview)
- [Opportunity guides](https://www.usemissa.com/guides)
- [How Missa verifies opportunities](https://www.usemissa.com/methodology)
- [Machine-readable summary](https://www.usemissa.com/llms.txt)
- [XML sitemap](https://www.usemissa.com/sitemap.xml)

The official organization or publication page remains the authority. Public
records keep the source link visible when available, distinguish confirmed
facts from details that need confirmation, and show a freshness signal when
the source record supports one. Readers should verify the official source
before applying.

## Repository

This repository contains the Missa web application and the public discovery
infrastructure that supports its creator-facing and organization-facing
experiences.
