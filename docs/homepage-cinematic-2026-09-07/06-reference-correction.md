# Reference correction after direct X-thread review

The user rejected the first homepage implementation as subpar. It is not an accepted creative result, regardless of passing functional checks. This correction supersedes the earlier direction where it conflicts.

Expanded the author's posts covering logic, composition, endpoint constraints, editing, generation integration and UI behavior; read the final testing and GitHub handoff posts.

These observations are not a frame-by-frame verification of every transition.

## What failed

The reference makes one world occupy the screen. Its centered person gives it presence and scale; architecture, saturated clothes, sky and sparse white typography carry the composition. A click changes a physical property through prepared footage. The controller collapses and the title disappears so the transformation gets attention. The last decoded video frame becomes the selected state; Reset reverses the physical event.

The first Missa implementation swapped empty-room stills beneath CSS sliding panels. Its interface and image occupy separate areas. The generic supporting sections add length without strengthening the central experience. Calling this a cinematic adaptation overstated the result. The implementation tested a substitute interaction successfully; it did not achieve the reference's creative intent.

## Corrected direction and order

1. Establish the full-screen composition around a person and a coherent physical world. Use sparse Missa typography and one compact controller; maintain a direct opportunity-navigation link.
2. Prove a real forward / held destination / reverse / base video cycle before producing more UI or expanding the number of branches. The supplied attributed reference footage can serve as a clearly identified engineering study; it is not original Missa artwork.
3. Produce Missa's own base and destination family with a fixed camera, matching subject position and a deliberate central mobile crop. Define what physically changes for each creative practice before generation. Do not simply relabel Clothing or Lighting as product categories.
4. Generate actual motion, inspect continuity and reverse behavior, then trim and pair the approved clips. Image wipes are not an acceptable stand-in for this proof.
5. Fit the interface to the footage. During playback collapse controls, withdraw the headline, hold the destination, and restore the interface during the return. Preserve stable video sources and decoded frames across handoffs.
6. Compare the running result directly against the demonstrated experience at desktop and mobile sizes before treating functional validation as sufficient.
