# Experiment archive

These files document the production path. They are not the final runtime clips. The website uses only files in `public/retake/`.

`images/` contains the earlier yellow/pink outfit concept, the streetwear version with a SCROLL pendant, the clean-walls revision, destination frame development and superseded lighting/cast images.

`videos/` contains nine saved source-generation attempts: the Clothing pilot and motion-only test, two Manhattan reveals, two lighting attempts and three jump-cut attempts. Later source iterations may be closer to the final result, but they still differ from the edited web exports.

`prompts/lighting-v1-original.md` is the superseded light-stripe brief. It is kept to show why the revised prompt describes the whole environment changing together. Do not use the stripe brief as the recommended lighting recipe.

No complete source-generation manifest with seeds or API request IDs was preserved. Filenames are historical production labels and do not certify the encoded FPS/resolution or model variant; inspect the file metadata if those properties matter.
