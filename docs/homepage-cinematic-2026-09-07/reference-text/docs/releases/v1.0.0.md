# v1.0.0 — Initial resource pack

## Included

- Comprehensive React/TypeScript/Vite website build specification.
- Eight edited forward/reverse web videos and five base/destination images.
- Five reconstructed image briefs and four video briefs, with provenance labels.
- Nine source-generation attempts and earlier image iterations in the experiment archive.
- Workflow, media mapping, troubleshooting and browser QA guides.
- Media SHA-256 manifest and a dependency-free Node validation script.
- MIT terms for text/scripts and CC BY 4.0 for covered images/videos; separate branding notice.

The LTX logo is included as a demo reference but excluded from the open-license grants.

## Verified

The package validator checks file hashes, required clip pairs, relative Markdown links and common sensitive-data patterns. Final publication also checks that the uploaded Git tree matches the local commit and that the repository is public.

## Not claimed

This is an asset and prompt pack, not a ready-to-run React application or an LTX API SDK. A clean-room rebuild from the prompt has not been browser-tested. No new image/video generation was run for this release. Source briefs do not recreate the edited footage pixel-for-pixel, and high-resolution editing masters are not included.

## Download

Use the release attachment `video-states-website-v1.0.0.zip`, or clone the repository. Both contain the same tracked resource files, without Git history or credentials in the ZIP.
