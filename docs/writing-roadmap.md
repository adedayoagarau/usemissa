# Writing room roadmap

The goal: a writing tool better than Scrivener, untouched by AI. How the room
works today is in `docs/writing-room.md`. This file tracks what is built and
what comes next, in the order agreed with the owner.

## Built

| Stage | What it gives the writer | Migration |
| --- | --- | --- |
| Write mode | A blank page, a timer, ten open-licence typefaces, device-first saving that never overwrites another device, entries, download | 0095 |
| Pages | Rich text on printed pages (A4, US Letter, A5, chapbook), a format for each page, every space and tab kept, titles, print and save as PDF | 0096 |
| Projects | Projects from templates, a binder to order pieces, loose pieces, an outline of synopses and statuses, compile to one manuscript | 0097 |
| Pagination | Text flows from page to page as it is written; pages the writer adds stay apart. The room moves to `/doc` | none |
| Free canvas | Any page can become a canvas of text boxes placed, sized and turned by hand, printed exactly | none |
| Snapshots, find, dark | Snapshots to compare and restore, find and replace across every page and box, a dark writing room | 0098 |
| Writing for a call | A piece tied to a call in the tracker: the call and checklist beside the draft, a live count against its word limit, page and blind-reading checks run on the piece in the browser | 0099 |
| Editor essentials | Page and section breaks as in Google Docs and Word, superscript and subscript, clear formatting, the Docs keys for strikethrough and word count, a word count with the selection and reading time, smart quotes and dashes as a choice, Tab nesting lists | none |
| Quiet writing | Quiet mode apart from the timer, focus on the paragraph or sentence in hand, typewriter scrolling, hiding the count, Escape kept in full screen | none |

## Next, in order

From the research in `docs/writing-research.md`, which has the findings,
sources and what each stage contains:

1. **G. Cards and corkboard.** Fields on every piece, a corkboard, an outliner
   with totals, saved views, editing several pieces as one text.
2. **H. Story bible.** Characters, places and items with "Appears in".
3. **I. Plot grid and structures.** Plotlines across the book, structure
   templates, pacing against beats, plotline gaps.
4. **J. Goals and history.** Deadline targets that skip days off.
5. **K. Timeline.** Story order and telling order, ages, continuity checks,
   then alternate branches.
6. **L. Book design and export.** Book interiors, standard manuscript format
   as DOCX, EPUB 3.
7. **M. Notes and research.** Margin notes, footnotes, research beside the
   draft.

## Later

- Tie a whole project to a call, and show the call's own required materials
  and prompts, not only the writer's checklist.
- Import from Word, Scrivener (`.scriv`) and Google Docs.
- "Make this a Work" and "Send to Tracker", so each version is tied to the
  call it went to.
- Feedback from a reading partner, from people only.

## Open decisions

- Default typeface: Newsreader now; EB Garamond draws every Yoruba, Igbo and
  Hausa letter checked.
- The one use of "AI" on the page, in the privacy promise, needs an owner
  decision before public launch.
