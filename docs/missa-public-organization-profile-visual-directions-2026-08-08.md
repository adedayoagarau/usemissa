# Missa public Organization profile visual directions

Date: 8 August 2026  
Status: Option 2 selected in the local library and applied to the existing local public route; deployment and full profile promotion blocked  
Selected review route: `/design-system/public-organization-profile`  
Comparison route: `/design-system/public-organization-profile-directions`

## 01 — Editorial profile

The Organization’s story and source-provided image establish identity before current Opportunities. This is strongest for institutions with rich public profiles, but it can delay the creator’s immediate task.

## 02 — Opportunity-first profile — selected

Compact Organization identity and official-source actions lead directly into active Opportunities. About, public Programs, and practice context remain supporting sections. This direction is selected because it prioritizes the creator’s decision without reducing the Organization to a logo, remains truthful with the current minimum data, and has the clearest phone transformation.

The current local product route uses the minimum-data version of this direction: name, published Opportunities, optional approved Opportunity media, and derived practice context. Unsupported identity, official-source, Program, Follow, and report features remain visibly absent rather than simulated.

## 03 — Program directory

Public Programs form the primary hierarchy, with Opportunities grouped beneath them. It is useful for large institutions but remains target-state until Program visibility and descriptions are explicitly public.

## Shared visual rules

- true white canvas with Aubergine emphasis;
- source-provided media is optional and never labelled “Organization photo” or “Opportunity photo”;
- no blanket verification, ratings, reviews, follower counts, confidence, freshness, or popularity metrics;
- active Opportunities precede institutional history;
- practice labels describe the displayed Opportunities, not the Organization’s expertise;
- official website and contact links are explicit external destinations;
- follow is private viewer state and never implies endorsement or newsletter consent;
- all three directions use the same content, taxonomy, state, and responsive fixtures;
- product promotion remains blocked.
