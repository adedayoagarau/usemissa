# Discovery beta and magazine index

## Scope and direction

Extend Missa’s existing public identity. Operate mode: anonymous creators find opportunities and compare magazines before visiting an official application destination. Discovery is the public promise; existing signed-in workflows are retained.

## Direction contract

THESIS: Make magazine identity and comparable evidence the reading order, with discovery as the beta entry point.
OWN-WORLD: Existing white canvas, Forest actions, Newsreader heading, Instrument Sans controls, Fragment Mono numeric measurements.
STORY: Browse without registration, compare relevant magazines, read their guidelines, share feedback.
FIRST VIEWPORT: Editorial heading and methodology alongside each other; genre navigation, labelled search and filters, then a restrained comparison table. Mobile keeps magazine, rank and score with row actions underneath.
FORM: Extension of the incumbent index and public shell; no new visual world or seed assignment.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Component evidence

- Static release state: metadata.static → BetaBadge → installed Badge outline. Studio badge-10 inspected. Wrapper sits beside the canonical SVG wordmark without changing the artwork.
- Data comparison: data.comparison → installed Table; Studio table-01 inspected. Compact internals in a Comfortable page.
- Search: input.short-text → Field/Input. Sort/tier: choice.single-native-mobile → NativeSelect. Filters/actions: installed Button, with pressed states; empty results: feedback.empty → Empty.
- Existing MagazineScheduleBadge, MagazineTrackerAction and ReportResponseDialog retain repository integration. Response success refreshes server data rather than inventing new scores in the browser.
- Public links use native navigation; genre links carry aria-current, and controls have visible labels. Pagination bounds results to 25 rows.
- Source research: https://ui.shadcn.com/docs/components/base/data-table supports composable table structure. Mobbin was searched for search/filter precedents, but no inspectable primary result was returned; no Mobbin design approval is claimed.

## Release boundary

No migration, deployment, ingestion, provider delivery, or production readiness certification is part of these local UI edits. Shared checkout contains pre-existing backend and rankings work. Public browse/detail access already exists. This change removes organization acquisition and account creation from public header/homepage; existing account actions and direct routes still exist. Hiding links is not access control.

Seed fallback is explicitly identified in the magazine list and its fee/schedule/reporting actions are suppressed. Database-sourced rows are not independently certified as accurate by this UI change. Seed fallback in other rankings surfaces remains a separate data audit item.

The repository-wide Impeccable build state refers to the September 3 opportunities hero, not this index. It was left untouched.
