# Missa Creator Home, Tracker Import, and Ask visual directions

Home, Import, and Ask are different jobs sharing one Profile shell. The comparison does not elevate them into primary navigation, fabricate a dashboard, write imported records, query production search, or expose operational source metadata.

## 01 — Focused task

One primary job and its consequence lead. Supporting context stays short and local.

Strengths:

- strongest phone hierarchy for a real next task;
- best default when Home has one reliable continuation or Ask has one bounded query;
- keeps Import consequences legible as a linear review.

Risks:

- slower comparison across many import rows;
- conversation history and competing Home work become secondary.

## 02 — Creator desk — selected

A durable work list and focused detail keep complex review and evidence visible together.

Strengths:

- strongest desktop Import row comparison;
- gives Ask conversation history and result evidence a stable place;
- supports Home attention work without turning it into metrics.

Risks:

- can overstate Home as a destination before a typed projection exists;
- secondary panes must collapse into route-like mobile detail, not tiny columns.

## 03 — Guided utility

Named stages and one current action make unfamiliar or high-risk work easier to recover. Utility context is visible on wide screens but does not become primary Profile navigation.

Strengths:

- clearest first import and partial-resume path;
- preserves staged decisions, confirmation, and receipt boundaries;
- helps explain Ask’s bounded scope without presenting a general-purpose assistant.

Risks:

- adds unnecessary structure to ordinary Home continuation;
- stage state must not imply that viewing equals completion.

## Shared state coverage

- Home: new account, useful no-activity state, one or several consequential tasks, equal deadlines/timezone, removed target, private preference conflict, partial failure, expired session, long/multilingual content, and no typed projection;
- Import: file/type/size/parsing states, mapping, exact and possible matches, taxonomy review, status conflict, duplicate rows, expired preview, concurrent Tracker change, explicit confirmation, no-op, offline, ambiguous/failed commit, and durable receipt;
- Ask: empty, results, no matches, taxonomy clarification, out-of-scope request, unavailable source, partial results, rate limit, unavailable collection, disabled capability, pending, failed/ambiguous send, history, long content, and RTL;
- Import match reasons use exact facts, never an implementation score;
- legacy practice values enter a canonical facet/alias/unresolved review and never silently become terms;
- Ask keeps Opportunity type, practice, fee, deadline, and geography as separate parsed filters and never turns intersections into fit or eligibility scores;
- 390px and 1280px full matrix checks, focused 320px, field/composer reachability, confirmation safety, and WCAG A/AA scans.

## Premium anatomy boundary

Premium dashboard, list/detail, stepper, upload, mapping table, review card, chat, source card, alert, and composer anatomy may be adapted. Metric walls, confidence/freshness widgets, chatbot avatars without evidence, general-purpose AI copy, nested interactive result cards, and hidden import consequences are rejected.

Option 02, Creator desk, is selected as the shared local composition. The focused-task and guided-utility alternatives remain available on the comparison route and may still inform individual narrow states. The selected route preserves all three utilities and all 48 fixtures. Product promotion remains blocked until the Home projection decision, durable import transaction/idempotency and taxonomy review, customer-safe Ask evidence, route/shell continuity, accessibility review, and explicit approval are complete.
