## 01 — Operating brief

A concise narrative review: three primary measures, one intake trend, and an attention list. It is strongest for an executive or occasional Viewer but compresses the relationship between Programs, Opportunities, reviews, and Work decisions.

## 02 — Program lens — selected

A scope-first operating dashboard with three defined primary measures, intake trend, review/decision health, Opportunity comparison, one-facet-at-a-time practice lens, and a durable data-quality panel.

Why selected:

- it mirrors how Program managers choose where to intervene;
- it keeps Submission, Work, assignment, and fully decided Submission grains visible;
- it adapts cleanly from desktop analysis to a vertical mobile review;
- it can project safely for Owner, Program manager, Reviewer, Finance, Legal, and Viewer roles;
- it supports real current data without inventing the strategic funnel that instrumentation cannot yet measure.

## 03 — Analysis table

A dense comparative table optimized for large portfolios and export preparation. It is powerful for analysts but too demanding as the default and weaker for narrow screens. Its table anatomy remains available as the Program lens comparison section.

## Shared visual rules

- true white canvas;
- Aubergine for active scope and primary emphasis;
- Lichen for completed states, Ochre for attention, Mineral Blue for neutral information;
- no gradient KPI cards, oversized decorative numbers, gauges, or meaningless arrows;
- metric title, grain, denominator, and exclusion status remain readable without a tooltip;
- charts always have a semantic table fallback and do not rely on color alone;
- the three directions remain available in the local comparison switcher.
