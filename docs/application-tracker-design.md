# My applications preview

Route: /design-system/my-applications. Experimental design composition; sample records persist only in this browser's localStorage. Not account-connected.

Uses installed Button, Field, Input, Textarea and NativeSelect for actions, labelled editing, and selection. Semantic colors, no new primitive or vendor installation. Policy and catalogue registered. Creator applies on the official URL once; opening it does not change status. User can explicitly set Submitted, Still working, or Not now.

Personal target and official date are distinct. Reminder preference and channel are design-only: no notification delivery. Calendar is a date-only agenda with downloadable ICS, not live calendar sync. Submitted, accepted, declined and archived records are excluded. Exact cutoff times/timezones and real provider synchronization remain integration work.

Validation: design-system check and web typecheck passed. Chromium tested adding/editing, reload persistence, calendar export, submitted exclusion and 390px overflow. Desktop screenshot inspected. Full device, 200% browser zoom, keyboard-only and provider delivery QA remain outstanding.

Next: review this interaction direction, then integrate account records, timezone-aware deadlines, notification scheduling/preferences and calendar provider sync with backend contracts. Do not claim export provides live synchronization or duplicate-free imports across calendar providers.
