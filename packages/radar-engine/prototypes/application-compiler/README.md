# Application Compiler prototype

**Question:** Can one deterministic, versioned component model compile the same verified opportunity into a truthful private application plan for different creative practices, while keeping eligibility, readiness, external fill, and submission as separate states?

This is throwaway logic-prototype code. It uses synthetic in-memory fixtures, performs no persistence or network calls, and must not be promoted directly into production.

Run it from the repository root:

```bash
npm run prototype:application-compiler --workspace=@missa/radar-engine
```

Use the keys shown at the bottom of the terminal. The entire application manifest is re-rendered after every action.
